<h2>
	<img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Accessibility.png" align="center" width="30" alt="Modularity"> Modularity
</h2>
<p>
	The project features a convenient module system. If you do not need certain recipes or entire crafting categories, you can easily remove them by simply deleting the corresponding folder from the archive.
</p>

<details>
<summary><img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Search.png" align="center" width="32" alt="Structure"> Structure</summary>
<h3>Folder Structure:</h3>
	<p>The internal structure is identical for both the recipes folder (<code>recipe</code>) and the conditions for unlocking them in the recipe book (<code>advancement/recipes</code>). The root folders are categorized by the method of item creation:</p>
	<ul>
	  <li><code>crafting</code> — <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Crafting_Table_JE4_BE3.png" align="center" width="32" alt="Crafting Table"> Crafting Table and the inventory crafting grid;</li>
	  <li><code>smelting</code> — <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Lit_Furnace_(S).gif" align="center" width="32" alt="Furnace"> Furnace;</li>
	  <li><code>blasting</code> — <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Lit_Blast_Furnace_(S)_JE1.gif" align="center" width="32" alt="Blast Furnace"> Blast Furnace;</li>
	  <li><code>stonecutting</code> — <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Stonecutter_JE2_BE1.gif" align="center" width="32" alt="Stonecutter"> Stonecutter;</li>
	  <li><code>smithing_transform</code> — <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Smithing_Table_JE2_BE2.png" align="center" width="32" alt="Smithing Table"> Smithing Table.</li>
	</ul>
	<p>Inside these folders, files are divided into logical categories. For example, the <code>crafting/wood_types/acacia</code> folder contains all alternative crafts using <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Acacia_Planks.png" align="center" width="32" alt="Acacia Planks"> Acacia Planks and <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Acacia_Log_(UD)_JE8_BE3.png" align="center" width="32" alt="Acacia Log"> Acacia Logs.</p>

<h3>File Naming Convention:</h3>
	<p>All file names follow a logical pattern: <code>[what_item_is_crafted]_[from_what_material].json</code>.</p>
	<p>For example, the path <code>data/ccore/recipe/crafting/utility/chest_logs.json</code> means crafting a <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Chest_(S)_JE2.png" align="center" width="32" alt="Chest"> Chest directly from <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Oak_Log_(UD)_JE8_BE3.png" align="center" width="32" alt="Log"> Logs.</p>
</details>

<details>
<summary><img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Stonecutter_JE2_BE1.gif" align="center" width="32" alt="Stonecutter"> Instructions for removing modules (using the stonecutter as an example)</summary>
<br>
<p>If you want to completely disable all new recipes for the <img src="https://raw.githubusercontent.com/iluxa69/craftcore/main/_assets/sprites/Stonecutter_JE2_BE1.gif" align="center" width="32" alt="Stonecutter"> Stonecutter, follow these steps:</p>
	<ol>
	  <li>Open the <code>.jar</code> or <code>.zip</code> file of the datapack using any archiver (e.g., 7-Zip or WinRAR).</li>
	  <li>Navigate to the path <code>data/ccore/recipe/stonecutting</code> and delete the <code>stonecutting</code> folder.</li>
	  <li>Navigate to the path <code>data/ccore/advancement/recipes/stonecutting</code> and delete the <code>stonecutting</code> folder as well (this will prevent error logs from appearing in the server console).</li>
	  <li>Run the <code>/reload</code> command in-game or restart the server to apply the changes.</li>
	</ol>
</details>
