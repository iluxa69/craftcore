<h2><img align="center" src="https://github.com/iluxa69/craftcore/raw/main/_assets/sprites/Recipe_book_button.png" width="32" alt="Recipe Book"> Integration with the Recipe Book</h2>
<p>Unlike most datapacks that simply add new crafting recipes, this project features full integration into the advancements/recipes system. This means you do not need to constantly check this page to look up a recipe. All new crafts will unlock exactly as they do in vanilla Minecraft — upon obtaining the required ingredient or performing a specific action.</p>
